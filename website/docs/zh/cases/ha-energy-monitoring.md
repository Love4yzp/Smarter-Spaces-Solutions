# 办公室能源管理试点项目

## 概览

本项目基于Home Assistant开源平台，结合智能断路器和网关设备，构建了一套完整的办公能源管理解决方案。通过实时监控用电数据、远程控制电路、提升用电安全性和数据可视化，为小型办公环境提供经济实用的能源管理方案。

## 项目背景与目标

为深入探索和验证现代物联网技术在提升办公环境能源管理效率与安全性方面的实际应用效果，我们在公司办公室内启动了本次智慧能源试点项目。此项目通过对现有办公电路进行实际改造，并集成先进的智能硬件与开源控制平台，旨在构建一个功能完善、可供展示和未来推广的能源管理样板。

**本项目核心目标及关联应用场景如下：**

| 试点目标                                                     | 关联应用场景说明                                             |
| :----------------------------------------------------------- | :----------------------------------------------------------- |
| ✅ **监控特定办公回路的用电情况**（例如：茶水间、公共设备区） | ✅ 帮助企业了解各功能区域或关键设备的用能状况，发现节能潜力。  |
| ✅ **增强回路安全性**（通过智能断路器的过载/漏电/短路保护功能） | ✅ 提升办公场所用电安全，预防潜在电气火灾等风险。              |
| ✅ **远程控制特定回路**（实现该回路的通/断电）                 | ✅ 便于IT或行政部门进行远程设备管理，例如节假日远程关闭非必要回路。 |
| ✅ **数据可视化**（展示实时功率、历史用电量）                 | ✅ 为能源审计、成本控制或（如共享办公空间）费用分摊提供数据支持。 |
| 🕒 **[未来规划] 场景自动化**（例如：基于时间、人员活动、能耗阈值的自动通断电） | 🕒 实现更智能的无人化管理，最大化节能效益，优化办公体验。      |

**本项目当前阶段不侧重于：**

* ❌ 极高精度的工业级计量需求。
* ❌ 对电路/设备毫秒级的快速控制响应。

## 项目实施过程与关键配置

### 硬件安装与电气改造

>[!WARNING]
> 本文涉及 220V 市电操作，具有较高风险。所有强电设备的安装、接线和改造工作，都应由具备相应资质的专业电工进行。非专业人士切勿自行尝试，以免发生触电、火灾等危险！

1. **回路选择与改造：** 由专业电工选定办公室内的合适回路（例如：特定区域的照明、插座混合回路），在确认安全后，将智能断路器接入该回路的电箱（或新增小型 উপ-电箱）。
2. **Home Assistant主机部署：** 将Home Assistant Green或同等主机通过网线连接至办公室局域网，通电启动。
3. **智能网关安装与联网：** 将智能网关安装在合适位置，连接电源，并通过RS485通讯线与智能断路器的通讯端口规范连接。确保智能网关通过以太网或配置好的Wi-Fi/4G网络接入局域网或互联网。
4. **[可选] ESPHome设备部署：** 若使用电流互感器方案，将预先刷写好ESPHome固件的ESP模块与电流互感器连接，并将其接入Wi-Fi网络。

### Home Assistant平台配置

1. **系统初始化与网络设置：** 确保Home Assistant系统正常运行，并配置好网络参数。
2. **集成关键设备：**
    * **智能网关/智能断路器：** 根据您选用的智能网关和断路器的数据通讯方式（如Modbus TCP, MQTT, 或特定厂商的集成），在Home Assistant中添加并配置相应的集成 (Integration)。正确设置IP地址、端口、Modbus地址、MQTT主题等参数。
        * _例如，如果网关支持Modbus TCP，则在Home Assistant中配置Modbus集成，定义相关的sensor（读取功率、电压、电流、电量）和switch（控制断路器通断）实体。_
    * **ESPHome设备：** 如果使用了基于ESPHome的电流互感器，Home Assistant通常能自动发现并提示添加，或通过ESPHome集成手动添加。
3. **实体（Entities）管理：**
    * 检查新接入的设备是否在Home Assistant中生成了对应的实体。
    * 对实体进行清晰、易懂的命名和归类（例如 `sensor.office_meeting_room_power`，`switch.office_lab_circuit`）。
4. **仪表盘 (Dashboard) 创建：**
    * 设计一个专门的Lovelace仪表盘，用于展示本试点项目的监控数据和控制界面。
    * 添加卡片类型：
        * **概览卡片：** 显示回路的总体状态、当前总功率等。
        * **传感器图表：** 展示功率、电压、电流、累计电量的实时值和历史曲线。
        * **开关控制卡片：** 提供对智能断路器所控回路的远程通/断操作按钮。
        * **[可选] 能耗分析卡片：** 利用Home Assistant的Energy Dashboard功能，或结合InfluxDB+Grafana进行更详细的能耗分析展示。

## 主要功能实现与效果评估

本办公室智慧能源试点项目成功运行后，实现了以下预定目标和核心功能：

* ✅ **精确的回路用电监控：**
  * Home Assistant仪表盘能够实时、准确地显示目标回路的电压、电流、瞬时功率及累计用电量。
  * 可追溯历史数据，为分析特定时段（如工作时间、夜间待机）的用能模式提供了可靠依据。
* ✅ **便捷的远程回路控制：**
  * 项目团队成员可通过授权的Home Assistant手机App或Web界面，随时随地安全地控制目标回路的通断。
  * 成功演示了在非工作时间远程关闭选定回路，以消除不必要的待机能耗。
* ✅ **增强的回路电气安全：**
  * （依赖智能断路器自身功能）智能断路器为回路提供了过载、短路及漏电（如具备该功能）保护。
  * Home Assistant可配置在检测到断路器状态异常（如跳闸，需断路器支持状态反馈）时，通过系统发送告警通知。
* ✅ **直观的数据可视化界面：**
  * 定制化的仪表盘使得非技术背景的行政或管理人员也能轻松理解回路的用能状况。

## 项目实施经验与价值思考

* **真实环境验证的重要性：** 在实际办公环境中进行部署和测试，能更早发现理论设计阶段未曾考虑到的问题（如网络信号、设备兼容性、实际负载特性等）。
* **专业电气工作不可或缺：** 任何涉及强电的改造，安全永远是第一位的。专业电工的参与是项目顺利和安全实施的根本保障。
* **开放平台的强大潜力：** Home Assistant的开放性和灵活性使得集成不同品牌、不同协议的硬件成为可能，为构建定制化解决方案提供了坚实基础。
* **数据是优化的起点：** 通过本试点项目收集到的精确能耗数据，为未来制定更细致的节能策略、评估设备能效、优化办公用能习惯提供了可能。
* **示范与推广价值：** 本试点项目成功验证了方案的可行性，其经验和模式可为其他办公室乃至小型商业体实施类似的能效提升项目提供有价值的参考。

## 总结与未来展望

本次办公室智慧能源试点项目，不仅成功实现了对特定办公回路的智能化监控与控制，更重要的是，它验证了一套低成本、高灵活性、可扩展的智慧能源管理解决方案在真实场景下的应用价值。这为我们后续在更广泛的商业环境中推广此类方案积累了宝贵经验。

**未来基于此试点项目的扩展方向：**

* **深化自动化策略：** 结合更丰富的传感器数据（如光照、人员密度、日程表），开发更智能、更精细化的自动节能控制逻辑。
* **横向扩展监控范围：** 将更多办公区域或类型的负载接入系统，实现全面的办公能源管理。
* **探索与楼宇自控系统(BAS)的联动。**
* **持续优化用户体验，** 提供更简洁易用的报表和控制界面。
